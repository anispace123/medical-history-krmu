## 🚀 GitHub-қа жүктеу және GitHub Pages арқылы сайтты ашу (Нұсқаулық)

Жоба жергілікті түрде Git репозиторийі ретінде дайындалған. GitHub-қа жариялау үшін келесі қарапайым қадамдарды орындаңыз:

### 1-қадам: GitHub-та жаңа репозиторий ашыңыз
1. [github.com](https://github.com) сайтына кіріп, жаңа репозиторий жасаңыз (мысалы, `medical-history-lecture-9`).
2. Репозиторийді **Public** етіп таңдаңыз.

### 2-қадам: Терминалда келесі пәрмендерді орындаңыз
```bash
# Жоба каталогына кіру
cd /Users/adilzan/Downloads/презентация

# Өзгерістерді бекіту
git add .
git commit -m "feat: XIX-XX ғғ. медицина тарихы интерактивті презентациясы (ҚРМУ 107Б)"

# GitHub репозиторийіңіздің сілтемесін қосу (өз логиніңіз бен репо атын жазыңыз)
git remote add origin https://github.com/<СІЗДІҢ_GITHUB_ЛОГИН>/medical-history-lecture-9.git

# Негізгі бұтаққа жіберу
git branch -M main
git push -u origin main
```

### 3-қадам: Сайтты 1 рет басу арқылы жариялау (GitHub Pages)
1. GitHub-тағы репозиторийіңіздің **Settings** (Параметрлер) бөліміне өтіңіз.
2. Сол жақтағы мәзірден **Pages** бөлімін таңдаңыз.
3. **Branch** бөлімінде `main` бұтағын және `/ (root)` папкасын таңдап, **Save** батырмасын басыңыз.
4. 1-2 минуттан кейін сайтыңыз мынадай ғаламдық сілтемеде ашылады:  
   👉 `https://<СІЗДІҢ_GITHUB_ЛОГИН>.github.io/medical-history-lecture-9/`
